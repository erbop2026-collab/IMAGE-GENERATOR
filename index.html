❓ Help & Feature Reference

Portion Calc helps catering kitchens turn cooked-portion plans into raw shopping lists, prep instructions, and cost breakdowns. Below is everything the app does.

Two main concepts: ingredients vs. recipes

An ingredient is a raw material with a raw → cooked conversion (rice, chicken, oil, eggs).
A recipe is a composite dish — one meal made of several ingredients (e.g. Chicken & Rice = 200 oz rice + 150 oz chicken + 50 oz sauce).

You can put either an ingredient OR a recipe directly into an order. Recipes get expanded into their component ingredients automatically when you Calculate.

Tabs

Setting up ingredients

Each ingredient has a Basic tab and a Pricing & Labor tab.

Basic: name, unit (oz / lb / cup / floz / qt / gal / ct), raw amount, cooked amount.
Example: 12 oz raw rice → 36 oz cooked. The app derives the ratio (3 cooked per 1 raw) and uses it everywhere.

Pricing & Labor (all optional):

  • Pack size — e.g. 25-lb sack. Lets the results round up to whole packs to buy.
  • Pot / Tray sizes — list as many as you have, with optional names ("small", "large"). The app fits the order with largest first; overflow goes into the smallest. The total pot count drives cooking labor.
  • Cost — value plus a mode: per measurement unit, per pack, or per piece.
  • Packaging cost — $ per single portion (e.g. takeout box).
  • 🍳 Cooking labor — time to cook ONE pot/tray, plus workers and $/hour. Total = pots needed × hours × workers × rate.
  • 📦 Packaging labor — separate from cooking. Choose basis: per single portion / per carton of N portions / per cooking batch. Total = units × hours × workers × rate.

Building an order

On the Calculate tab:

  1. Order Details — name and event date stamp into history.
  2. Find / Quick-add — type an ingredient or recipe name. Matching chips appear (recipes show with 🍲); tap one to add it to the order. The same search also filters the dropdowns inside existing ingredient rows. Tapping a chip for an ingredient already in the order adds another size to the same group instead of duplicating.
  3. Cooking Order — each row is one ingredient (with one or more sizes) or one recipe (with a meal count). Reorder rows with ▲▼; duplicate a whole group with 📋.
  4. Calculate — generates the results card and stores a snapshot in History.

Reading the results

For each ingredient (including those expanded from recipes):

  • Total raw + total cooked + portion count.
  • Pack rounding ("3 packs of 25 lb"), pot plan ("2 × large (10 oz) + 1 × small (5 oz)").
  • Ingredient / Packaging / Cook labor / Pack labor breakdown, then a subtotal.

A "Cost per single portion" section answers "how much does ONE 8 oz vs ONE 12 oz portion cost?" using the effective $/cooked-unit so pack-mode rounding flows through correctly.

Bulk import from Excel / Google Sheets (CSV)

The Ingredients tab has a 📥 Bulk import (CSV) card. Paste a CSV table or pick a .csv file. From Excel: File → Save as → CSV. Tap 📄 Load template to see a working sample.

Required columns: name, unit, raw, cooked. Header is case-insensitive; spaces / underscores / dashes are ignored.

Optional columns: packSize, cost, costMode (measure / pack / piece), packagingCost, potSizes (e.g. small:5;large:10), laborHours, laborWorkers, laborRate, packLaborHours, packLaborWorkers, packLaborRate, packLaborBasis (portion / carton / batch), cartonSize.

Rows whose name matches an existing ingredient are updated in place; new names are added. After import you'll see a toast with added / updated / skipped counts; full per-row issues print to the browser console.

Recipes (composite dishes)

A recipe is one meal made of several ingredients. Example: Chicken & Rice = 200 oz rice + 150 oz chicken + 50 oz sauce. Define recipes in the 🍲 Recipes tab — each component picks an ingredient from your catalog plus a per-meal amount.

In the order, tap + Add Recipe (or quick-add via search) and enter the number of meals. The app expands each recipe into raw amounts of every component ingredient, summed into the regular ingredient totals — so the kitchen sees one consolidated shopping list and prep plan.

Recipes are flat: each component is a basic ingredient, not another recipe. (Nesting is intentionally not supported.)

Reverse calculation

On the Ingredients tab: pick an ingredient, enter the raw amount you have plus a portion size — the app tells you how many portions you can serve.

Sharing the order

Three export modes plus JSON backup, all in the Export & Backup card.

  • 🍳 For Kitchen — formatted prep sheet: raw amounts, pack/pot counts, portion list. No prices anywhere.
  • 💼 For Office — full cost breakdown plus per-portion price.
  • 💾 JSON backup — full state snapshot for restore.
  • 📲 Share — opens your phone's share sheet (WhatsApp, Mail, etc.).
  • 🖨 Print / PDF — print directly or "Save as PDF" from the print dialog.
  • 📥 Import — paste JSON or pick a file. Replaces all data after a confirmation.

History

Every Calculate saves an entry with the order name, date, rows, and totals. Tap ↻ Load to restore an entry into the editor; tap 🗑 to delete one.

Data persistence

Your data is stored in the app's local storage. It survives:

  • Closing and reopening the app.
  • Restarting the phone.
  • Updating the app to a new version (when installed over the previous build).

Your data is wiped if you:

  • Uninstall the app (Android removes its data partition).
  • Clear app data from Android settings.
  • Replace your phone.

Best practice: use 💾 JSON backup periodically and store the file in Drive / WhatsApp / email. The app will gently remind you with a toast if a week passes without a backup. To restore, paste or pick the JSON in the Import field.
